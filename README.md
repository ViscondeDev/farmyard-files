## The Game

The Farmyard Files is a detective puzzle game developed for the **Brackeys Game Jam 2026.2**, around the theme **"Trust No One."**

You play as a detective investigating absurd incidents on a farm. Each case requires you to compare testimonies against evidence, take notes, and determine who is telling the truth — and ultimately who is responsible.

The game combines logic puzzles with a lighthearted farm setting and a noir-inspired presentation.

**Platform:** HTML5 · **Input:** Mouse

## Team

### Visconde — Lead Programmer

Responsible for:
* Game systems and gameplay programming
* Level design
* Asset integration

The main technical challenge was building the investigation system so that new cases could be created by combining existing systems and configuring data, rather than writing new gameplay code for every case.

This data-driven approach made the game's different mechanics reusable and allowed new investigations to be assembled from existing resources.

## Development

**Engine:** Godot  
**Language:** GDScript  
**Development time:** 7 days  
**Team size:** 4

The project uses a modular, data-driven architecture to keep investigation mechanics reusable and make the creation of new cases primarily a matter of configuring data.

A level loader and scene transition system were also reused from a previous project.
